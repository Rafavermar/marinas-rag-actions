Política de Privacidad — Marinas RAG Actions

Última actualización: 2025-12-15

1) Responsable

Responsable: RVM
Contacto: rafavmdev@gmail.com

2) Qué es este servicio

“Marinas RAG Actions” es una API que ayuda a consultar información indexada (texto/tablas) sobre tarifas y condiciones de amarres de marinas deportivas.

3) Datos que se procesan

  • Datos que envía el usuario: el texto de su consulta (por ejemplo: días, eslora, manga, calado, temporada) y, si aplica, identificadores de marina (marina_id) o de resultados (ids).
  • Datos técnicos (logs): como en la mayoría de servicios web, pueden registrarse datos técnicos necesarios para operar y depurar (por ejemplo: fecha/hora, endpoint, código de respuesta, y otros metadatos técnicos del servicio).
  • Datos indexados: el sistema almacena contenido indexado de fuentes públicas (p. ej. páginas de marinas) para poder responder consultas. No está diseñado para almacenar datos personales del usuario.

4) Finalidad

  • Responder consultas y recuperar fragmentos relevantes (RAG) desde la base indexada.
  • Mantener la seguridad y el correcto funcionamiento del servicio (diagnóstico y prevención de abuso).

5) Qué NO hacemos

  • No vendemos datos.
  • No pedimos credenciales, tokens ni secretos.
  • No intentamos identificar al usuario.

6) Compartición y terceros

Cuando usas el GPT en ChatGPT, partes relevantes del mensaje pueden enviarse a esta API para responder. La API se ejecuta en infraestructura de terceros (por ejemplo, proveedor cloud) y puede utilizar servicios de base de datos gestionados. Recomendación: no introduzcas datos sensibles o innecesarios.

7) Retención

El contenido indexado se conserva para ofrecer el servicio. Los logs técnicos, si existen, se conservan el tiempo mínimo necesario para operar y depurar el sistema.

8) Seguridad

Aplicamos medidas razonables para proteger el servicio (por ejemplo, control de acceso en endpoints administrativos fuera del GPT). Ningún sistema es 100% infalible.
